# DoneChan 通知协议

当本轮对话完成了一项**用户明确交办的完整任务**（修完 bug、交付功能、跑完构建/测试、
完成重构等），在回复的**最后一行**追加一条 HTML 注释标记。DoneChan 会把标记里的内容
通过 Server酱³ 推送到用户的手机。

## 格式

<!--donechan: {"title": "一句话标题（≤30字，可带 emoji）", "desp": "Markdown 正文，写给收通知的人看", "short": "卡片摘要（可选）", "tags": "竖线|分隔|标签（可选）"}-->

## 要求

- 只在**任务真正完成**时使用；纯问答、半途中断、等待用户输入时**不要**加标记。
- `title` 用一句话说清"做成了什么"，例如 `✅ 登录模块重构完成，测试全绿`。
- `desp` 面向不在电脑前的人：做了什么、结果如何、有没有需要注意的风险。可用
  Markdown（加粗、列表、链接）。不要包含密钥、token 或其他敏感信息。
- 标记必须是回复的最后一行，且独占一行。
- 一轮回复只放一条标记；没有合适的推送时机就不放。
